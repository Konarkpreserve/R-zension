# Purpose

Typography is one of the strongest elements of the R-zension brand.

It should communicate confidence, intelligence, precision, and elegance before users read the content itself.

Typography is responsible for:

- Hierarchy
- Readability
- Emotion
- Visual rhythm
- Brand identity

---

# Typography Philosophy

Typography should feel:

• Premium

• Spacious

• Confident

• Modern

• Calm

• Easy to scan

It should never feel:

• Dense

• Corporate

• Overdecorated

• Compressed

• Loud

---

# Font Families

## Primary Font

Plus Jakarta Sans

Purpose

- Headlines
- Navigation
- Buttons
- Cards
- Dashboard
- Product UI

Reason

Modern, geometric, friendly and premium.

---

## Secondary Font

Inter

Purpose

- Paragraphs
- Body copy
- Documentation
- Forms
- Tables

Reason

Excellent readability on digital interfaces.

---

## Monospace Font

JetBrains Mono

Purpose

- Code
- API Keys
- IDs
- Technical values
- Numbers requiring alignment

Never use monospace for paragraphs.

# Numbers

Numbers should have visual importance.

Examples

Score

Rank

Percentage

Growth

Revenue

Use:

- Tabular figures when alignment matters
- Monospace where precision is important

---

# Oracle Typography

Oracle should feel intelligent.

Large confident headings.

Minimal text.

Short sentences.

Examples

✔ Momentum increasing.

✔ Opportunity detected.

✔ Confidence: 92%.

✘ Long conversational paragraphs.

Oracle communicates insights,

not conversations.

---

# Leaderboard Typography

Ranks should dominate.

Usernames support the rank.

Movement indicators remain visually subtle.

Example

#12

Alex Johnson

▲ +3

The rank is always the focal point.

---

# Dashboard Typography

Every widget follows:

Title

↓

Primary Metric

↓

Explanation

↓

Action

The primary metric should always be visually dominant.

---

# Hero Typography

Landing page hero should contain:

One massive headline.

One supporting paragraph.

One clear CTA.

Avoid multiple paragraphs.

Avoid marketing buzzwords.

Users should understand the message within five seconds.

---

# Paragraph Rules

Maximum line length

80 characters

Preferred

60–70 characters

Reason

Improves readability.

---

# Alignment

Headings

Left aligned

Body text

Left aligned

Statistics

Right aligned where comparison matters

Centered text

Only for

- Hero
- Empty States
- Success Screens

---

# Text Hierarchy

Every screen should follow:

Title

↓

Subtitle

↓

Primary Information

↓

Supporting Information

↓

Metadata

Never compete for attention.

---

# Emphasis Rules

Use bold sparingly.

Use color only for meaning.

Avoid:

- Underlines
- ALL CAPS paragraphs
- Excessive italics

---

# Capitalization

Navigation

Title Case

Buttons

Sentence case

Headings

Sentence case

Body

Sentence case

Avoid writing everything in uppercase.

---

# Truncation Rules

Long text should truncate gracefully.

Use tooltips for overflow.

Never allow text to break layouts.

---

# Accessibility

Minimum font size

14px

Preferred body size

16px

Line spacing should always support readability.

Maintain WCAG contrast ratios.

Never rely on color alone for emphasis.

---

# Responsive Typography

Desktop

100%

Tablet

95%

Mobile

90%

Do not simply scale everything equally.

Maintain hierarchy.

---

# Typography Checklist

Every screen should answer:

✓ Is hierarchy obvious?

✓ Is reading effortless?

✓ Are headings consistent?

✓ Are paragraphs easy to scan?

✓ Does typography create breathing room?

✓ Does it feel premium?
