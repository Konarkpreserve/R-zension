# Purpose

This document defines every color used throughout the product.

Colors are not chosen because they look attractive.

Every color must communicate purpose.

Every color should improve usability, hierarchy and emotion.

---

# Design Philosophy

The interface should feel like:

• Night

• Intelligence

• Precision

• Momentum

• Confidence

Not:

• Gaming RGB

• Neon overload

• Crypto dashboard

• Hacker terminal

• Generic SaaS

# Data Visualization

Charts should never rely only on color.

Every visualization should also communicate using:

Shape

Labels

Icons

Patterns

Primary chart colors

Blue

Emerald

Cyan

Violet

Avoid using more than five colors in a single chart.

---

# Gradients

Gradients should be subtle.

Preferred combinations

Ascension Blue → Oracle Cyan

Oracle Cyan → Zenith Violet

Deep Navy → Black

Avoid rainbow gradients.

Avoid oversaturated colors.

---

# Glow Effects

Glow should enhance focus.

Never dominate the screen.

Use glow only for

Hero

Oracle

Hover

CTA

Active navigation

Maximum opacity

20%

Maximum blur

40px

---

# Shadows

Primary Shadow

Soft black

Low opacity

Large blur

Hover Shadow

Slightly stronger

Still soft

Never use harsh drop shadows.

# Dark Mode

Dark mode is the default experience.

Every component must be designed for dark mode first.

---

# Light Mode

Light mode is optional.

If implemented in the future,

colors should preserve the same hierarchy and emotional experience.

---

# Color Usage Rules

✔ One primary accent per screen.

✔ Neutral backgrounds.

✔ Bright colors only for actions.

✔ Reserve Oracle colors for Oracle.

✔ Reserve success colors for achievement.

✔ Keep visual noise low.

✘ Never use random accent colors.

✘ Never color everything.

✘ Never create rainbow dashboards.

✘ Never sacrifice readability for aesthetics.

---

# Future Expansion

The color system should support:

- Seasonal themes
- Brand customization
- Organization themes
- Accessibility themes
- High contrast mode

without changing the underlying design language.
