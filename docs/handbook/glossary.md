The glossary exists to

# General Terms

## R-zension

The AI-powered personal growth platform that helps users measure, understand, and improve their progress through goals, analytics, rankings, and Oracle intelligence.

---

## Oracle

The AI intelligence engine of R-zension.

Oracle provides

- Recommendations
- Predictions
- Insights
- Learning Guidance
- Productivity Suggestions

Oracle never performs actions automatically.

---

## User

A registered individual using the platform.

Examples

- Student
- Professional
- Learner

---

## Organization

A company, university, institution, or team that manages members within R-zension.

---

## Administrator

A privileged user responsible for managing the platform.

---

## Super Administrator

Highest privileged administrator with unrestricted platform access.

---

# Goal System

## Goal

A measurable objective created by a user.

Examples

- Complete React Course
- Reach Top 100
- Finish Portfolio

---

## Milestone

A smaller task contributing toward a goal.

One goal can contain multiple milestones.

---

## Progress

The completion percentage of a goal or milestone.

Range

```
0–100%
```

---

## Completion

The state indicating that a goal or milestone has been successfully finished.

---

## Goal Category

A classification used to organize goals.

Examples

- Learning
- Career
- Health
- Productivity

---

## Goal Priority

Indicates importance.

Values

- Low
- Medium
- High
- Critical

---

# Ranking System

## Leaderboard

A ranked collection of users.

---

## Rank

The numerical position of a user within a leaderboard.

Example

```
#15
```

---

## Score

The numerical value used to determine ranking.

---

## Percentile

A comparison metric indicating how a user performs relative to others.

---

## Season

A defined ranking period.

Examples

- Monthly
- Quarterly
- Annual

---

# Oracle Terms

## Recommendation

An AI-generated suggestion intended to improve user outcomes.

---

## Insight

An explanation generated from user data.

---

## Prediction

A forecast generated by Oracle.

Examples

- Goal Completion Probability
- Ranking Forecast
- Engagement Risk

---

## Confidence Score

Oracle's confidence in a prediction.

Range

```
0.0 – 1.0
```

---

## Oracle History

A record of previous Oracle recommendations and insights.

---

# Analytics

## KPI

Key Performance Indicator.

A measurable value representing user performance.

---

## Trend

A measurable pattern observed over time.

---

## Streak

The number of consecutive periods in which a user maintains an activity.

---

## Activity

A recorded user action.

Examples

- Goal Created
- Goal Completed
- Login
- Achievement Earned

---

# User Profile

## Profile

The public or private identity of a user.

---

## Achievement

A badge or accomplishment earned through platform activity.

---

## Badge

A visual representation of an achievement.

---

## Skill

A measurable capability tracked within R-zension.

---

## Portfolio

A collection of projects, certifications, and accomplishments displayed by a user.

---

# Authentication

## Access Token

A short-lived JWT used for authenticated API requests.

---

## Refresh Token

A secure token used to obtain new access tokens.

---

## Session

An authenticated login instance.

---

## RBAC

Role-Based Access Control.

Controls access based on assigned roles.

---

# Engineering

## API

Application Programming Interface.

---

## Endpoint

A specific API route.

Example

```
GET /goals
```

---

## Service

Contains business logic.

---

## Repository

Responsible for data access.

---

## Controller

Handles HTTP requests and delegates work to services.

---

## Middleware

Software executed before request handlers.

---

## Migration

A version-controlled database schema change.

---

## ORM

Object-Relational Mapping.

Maps application objects to database tables.

---

# Design

## Component

A reusable UI building block.

---

## Design System

The collection of reusable design standards and UI components.

---

## Responsive Design

An interface that adapts to different screen sizes.

---

## Empty State

The UI shown when no data exists.

---

## Skeleton

A loading placeholder displayed while content loads.

---

## Toast

A temporary notification displayed to the user.

---

## Modal

A dialog requiring user interaction before continuing.

---

## Drawer

A panel that slides into view from a screen edge.

# Security

## Authentication

Verifying user identity.

---

## Authorization

Determining whether a user can perform an action.

---

## Audit Log

An immutable record of important system events.

---

## Rate Limiting

Restricting request frequency to protect services.

---

## CSRF

A web security attack prevented through token validation.

# Product Principles

## Human-in-the-Loop

Users always make the final decision.

Oracle assists but never replaces user judgment.

---

## Secure by Default

Every feature should prioritize security without requiring user intervention.

---

## Privacy by Design

Privacy considerations are incorporated into every stage of product development.

---

## Explainability

Oracle recommendations should clearly explain why they were generated.
